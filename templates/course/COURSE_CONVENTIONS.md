# Course conventions

Additions and changes to lectern's `conventions/SCRIPT_CONVENTIONS.md` and
`conventions/STYLE.md` for this course. Where this file disagrees with them, this
file wins.

Delete the examples below and write your own. Keep each rule short, and say why
when the reason isn't obvious; whoever translates your scripts will follow these
literally.
